### 실행 방법
1. '기말 프로젝트' 폴더 내의 `login.html` 파일을 크롬(Chrome) 등의 웹 브라우저로 엽니다.
2. 구글 또는 카카오 로그인 버튼을 눌러 서비스를 시작합니다.



### 소스코드 구조
- **나들이_로고.png**: 웹 앱 메인 심볼 로고 이미지

- **나들이_로고_글자.png**: 푸터 영역 텍스트 로고 이미지

- **common.css**: 상단, 하단바 및 공통 레이아웃, Pretendard 폰트 스타일 정의

- **common.js**: 드롭다운 메뉴 및 로그아웃 등 공통 스크립트 모듈

- **login.html**: 구글/카카오 OAuth 로그인

- **home.html**: 메인 대시보드 (내 여행, 내 친구 및 새 일정 제안 알림)

- **myTrip.html**: 전체 여행 목록 조회, 이름 수정 및 삭제 기능 관리

- **addTrip.html**: 신규 여행 생성

- **tripDetail.html**: 선택한 여행의 일차별 일정 확인

- **editPlan.html**: 일차별 장소 순서 변경, 수정, 삭제

- **sharePlan.html**: 카카오맵 Web API 기반 장소 검색 및 일정 제안/수락/거절

- **map.html**: 일차별 일정 시각화 (카카오맵 마커 및 LatLngBounds 카메라 줌 자동 맞춤)

- **myPage.html**: 현재 로그인한 계정의 정보(이름, 이메일, 프로필 사진) 및 고유 회원 코드 확인

- **myFriend.html**: 친구 목록 확인 및 고유 코드를 이용해 새 친구 추가
